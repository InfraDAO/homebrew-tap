# Homebrew Tap

Custom Homebrew formulae for [InfraDAO](https://github.com/InfraDAO) projects.

## Setup

```sh
brew tap infradao/tap
```

## Formulas

### cinder

Developer CLI for Canton Network: runs filters over a validator's PQS and
explores what it holds.

```sh
brew install infradao/tap/cinder
```

## Supported platforms

| Platform      | cinder |
|---------------|--------|
| macOS ARM     | yes    |
| macOS Intel   | yes    |
| Linux x86_64  | yes    |
| Linux ARM64   | yes    |

## Upgrading

```sh
brew update
brew upgrade cinder
```

`Formula/cinder.rb` is generated by the release workflow on every release and
should not be edited by hand. Issues go to
[InfraDAO/canton-indexer-releases](https://github.com/InfraDAO/canton-indexer-releases/issues).
