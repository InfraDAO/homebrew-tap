# Homebrew Tap

Custom Homebrew formulae for [InfraDAO](https://github.com/InfraDAO) projects.

## Setup

```sh
brew tap infradao/tap
```

## Formulas

### canton-indexer

Indexing and query engine for Canton Network.

```sh
brew install infradao/tap/canton-indexer
```

## Supported platforms

| Platform      | canton-indexer |
|---------------|-----------------|
| macOS ARM     | yes             |
| macOS Intel   | yes             |
| Linux x86_64  | yes             |
| Linux ARM64   | yes             |

## Upgrading

```sh
brew update
brew upgrade canton-indexer
```

`Formula/canton-indexer.rb` is generated by the canton-indexer release
workflow on every release and should not be edited by hand. Issues go to
[InfraDAO/canton-indexer-releases](https://github.com/InfraDAO/canton-indexer-releases/issues).
